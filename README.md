# Perezosos Shop — catálogo inicial

## Cómo abrirlo
1. Descomprime la carpeta.
2. Abre `index.html` en tu navegador. Para desarrollo, se recomienda usar la extensión Live Server de VS Code.

## Antes de publicar
- Abre `script.js` y cambia `WHATSAPP_NUMBER = "521XXXXXXXXXX"` por tu número con código de país, solo números. Ejemplo de formato para México: `521XXXXXXXXXX` (sustituye las X; no incluyas +, espacios ni guiones).
- Edita el arreglo `products` en `script.js`: nombres, precios, categorías, descripción, colores e imágenes.
- Las imágenes actuales de productos son fotografías de ejemplo enlazadas desde Unsplash. Sustitúyelas por fotos propias antes de publicar.
- La página es un catálogo front-end: no procesa pagos ni administra inventario en servidor.
- Para publicar en internet puedes usar GitHub Pages, Netlify o un hosting con soporte para sitios estáticos.

## Archivos
- `index.html`: estructura de la página.
- `styles.css`: diseño responsive y paleta de colores.
- `script.js`: productos, filtros, búsqueda, carrito local y pedido por WhatsApp.
- `assets/`: imágenes de referencia de la mascota proporcionadas para el proyecto.


## Diseño responsivo
La página incluye puntos de adaptación para escritorio, tabletas y móviles (incluyendo pantallas pequeñas), cuadrícula de productos adaptable y menú móvil desplegable.
